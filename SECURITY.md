# Sicurezza

## Versioni supportate

Il progetto è un prototipo e non ha ancora release stabili supportate. Le
correzioni di sicurezza vengono applicate al branch `main` senza SLA.

## Segnalare una vulnerabilità

Non aprire una issue pubblica. Usa **Security → Report a vulnerability** nel
repository GitHub e includi impatto, passi minimi di riproduzione e una possibile
mitigazione. Evita dati personali, credenziali reali e dettagli non necessari.

Il canale di private vulnerability reporting deve essere abilitato prima di
rendere pubblico il repository. Le segnalazioni vengono valutate in modalità
best effort e non è previsto un programma di ricompense.

## Confini del prototipo

`services/backend` è uno scaffold locale in-memory: non è autorizzato per un
deploy pubblico, non accetta segnalazioni civiche reali e non deve ricevere dati
personali. Le richieste relative a problemi del territorio vanno inviate ai
canali ufficiali dell'ente competente, non a questo repository.
