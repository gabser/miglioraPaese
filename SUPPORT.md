# Supporto

Il progetto è un prototipo open source senza SLA o supporto commerciale.

Per bug riproducibili, problemi di setup o proposte tecniche:

1. cerca prima tra le issue esistenti;
2. usa il template GitHub appropriato;
3. indica sistema operativo, browser e versione Flutter;
4. allega solo log minimi e già privati di dati personali.

Non usare le issue per vulnerabilità, credenziali, segnalazioni civiche reali o
richieste ai Comuni. Per la sicurezza segui `SECURITY.md`; per problemi del
territorio usa i canali ufficiali dell'ente competente.
